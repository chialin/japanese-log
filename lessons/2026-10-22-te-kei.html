て形怎麼變

文法 · Grammar · 2026 / 10 / 22

て形是從動詞原型變出來的，但不是直接加 て：看最後一個字換音，以及它跟五段動詞那張表的關係

1.0x
💡 這篇要學的是什麼
寫 10/21〈歩いて行きます〉的時候冒出一個問題：て形是用動詞原型去變的嗎？ 答案是對，但不是在原型後面直接加 て。歩く 不會變成 歩くて，而是把最後的 く 換掉，變成 歩いて。
這篇先把各種結尾怎麼換整理成一張表，再回頭接上 8/9〈什麼是五段動詞〉那張 あいうえお 的表： 那篇最後說 住んで 是「另一種音變，不在這五格裡」，這篇就是在講那個音變是怎麼來的。 最後看一段動詞為什麼不用換音，以及 た形 為什麼跟て形變法一模一樣。
一、以原型最後一個字為主軸，把て形的變法排出來

動詞原型（辭書形）最後一個字一定是う段的音，這在 8/9〈什麼是五段動詞〉第一節講過。 要變成て形，就看這個字是哪一個，照下表換掉。按 ▶ 可以聽て形的唸法。

う・つ・るって 買かう → 買かって、待まつ → 待まって、走はしる → 走はしって
む・ぶ・ぬんで 飲のむ → 飲のんで、遊あそぶ → 遊あそんで、死しぬ → 死しんで
くいて 歩あるく → 歩あるいて、書かく → 書かいて

うつる って、むぶぬ んで、く いて、ぐ いで、す して。 五段的部分就這五組，唸熟之後看到結尾就能直接接上。一段動詞跟不規則的 する、来る、行く 另外記。
二、て形是從い段那一格變出來的，所以不在五段那張表裡

8/9〈什麼是五段動詞〉把五段動詞的變化排成 あ・い・う・え・お 五格：字幹不動，最後一個字換到哪一段，就是哪一種意思。 那篇最後提到 住んで 是「另一種音變，不在這五格裡」。原因是て形不佔自己的一格，它是從 い段那一格（也就是ます形去掉ます的樣子）出發，接上 て，再變一次音。

從い段接上 て，再變音

書かく → い段 書かき → 書かきて → 書かいて
買かう → い段 買かい → 買かいて → 買かって
住すむ → い段 住すみ → 住すみて → 住すんで
話はなす → い段 話はなし → 話はなして（不用再變）

所以前面那張表也可以從ます形倒回去想：把 ます 拿掉，剩下的就是い段那一格，再照規則變音。 先看幾個例子：

原型ます形去掉ます（い段）て形
歩あるく 歩あるきます 歩あるき 歩あるいて
走はしる 走はしります 走はしり 走はしって
並ならぶ 並ならびます 並ならび 並ならんで

平常講話學到的動詞多半是ます形，所以從ます形轉通常比較快。規則跟第一節的表是同一套， 只是看的那個字從う段換成い段：

ます形去掉ます，最後一個字換成例子
い・ち・りって 買かいます → 買かって、待まちます → 待まって、走はしります → 走はしって
み・び・にんで 飲のみます → 飲のんで、並ならびます → 並ならんで
きいて 歩あるきます → 歩あるいて
ぎいで 泳およぎます → 泳およいで
しして 話はなします → 話はなして、します → して
え段（食べ、寝、教え）直接加 て 食たべます → 食たべて、寝ねます → 寝ねて

這個方法有一個好處：去掉ます後是え段結尾的，一定是一段動詞，直接加 て 就好。 從原型看的話，食べる 和 走る 都是 る 結尾，反而要多判斷一次。

⚠️ 去掉ます後是い段結尾的，有可能是一段動詞
一段動詞也有い段結尾的（借りる、起きる、見る），它們的ます形跟五段動詞長得一樣，光看ます形分不出來：
ます形類別（原型）て形
帰かえります五段（帰かえる） 帰かえって
借かります一段（借かりる） 借かりて
書かきます五段（書かく） 書かいて
起おきます一段（起おきる） 起おきて
見みます一段（見みる） 見みて
帰かえります → 帰かえって
kaerimasu → kaette
回家（五段）
借かります → 借かりて
karimasu → karite
借（一段）

帰ります 和 借ります 都是「り＋ます」，て形卻一個是 って、一個是 て。行きます 也一樣是例外，要變成 行って。 所以平常講話從ます形轉比較快，遇到い段結尾、又不確定是哪一類的動詞，再回頭想原型，用 8/9〈五段 vs 一段〉的方法判斷。

三、音會變是因為原本的唸法不順口

書きて、住みて 這種「沒變音」的說法，在古典日文裡是真的這樣講的。 後來大家講快了，嘴巴自動把音簡化，就固定成現在的樣子。日文把這種變化叫 音便（おんびん）， 依照變出來的音分成三種：

名稱變成什麼音哪些結尾例子
い音便き・ぎ 變成 いく・ぐ 書かきて → 書かいて、泳およぎて → 泳およいで
促音便變成小っ（停一拍）う・つ・る 買かいて → 買かって、走はしりて → 走はしって
撥音便變成 ん，て 也跟著變 でむ・ぶ・ぬ 飲のみて → 飲のんで、遊あそびて → 遊あそんで
📝 促音 っ 的唸法在 5/9〈濁音・促音〉學過。 ぐ 變成 いで、む・ぶ・ぬ 變成 んで，て 都變成濁音 で，原因是前面的音本來就是濁音（ぐ・ぶ）或鼻音（む・ぬ），て 被帶著一起變濁。 す 的 して 唸起來本來就順，所以沒有變。
四、一段動詞不用換音，但 る 結尾要先分清楚是哪一類

一段動詞的い段（ます形去掉ます）本來就是 食べ、見 這種乾淨的樣子，接上 て 唸起來很順，所以直接加 て 就好，不會變音。 麻煩的是，一段動詞的原型都是 る 結尾，五段動詞也有 る 結尾的，兩種的て形完全不同：

原型類別ます形て形
食たべる一段 食たべます 食たべて
見みる一段 見みます 見みて
走はしる五段 走はしります 走はしって
帰かえる五段 帰かえります 帰かえって

已經知道ます形的話，看 る 有沒有變成 り：走ります、帰ります 的 る 變成 り，是五段；食べます、見ます 的 る 直接不見，是一段。 只知道原型的時候怎麼判斷，8/9〈五段 vs 一段〉有三步判斷流程。

五、た形的變法跟て形完全一樣

8/12〈過去式 た形〉第二節的變法，其實就是把て形的 て 換成 た、で 換成 だ。 學會一個，另一個就會了：

原型て形た形
買かう買かって買かった
飲のむ飲のんで飲のんだ
歩あるく歩あるいて歩あるいた
食たべる食たべて食たべた
行いく行いって行いった

〈ジムとカフェに行きました〉那篇會話裡的 並んだ（排了隊）、疲れた（累了），就是 並んで、疲れて 的 て 換成 た。

六、變好的て形可以接在很多東西前面

て形本身不收尾，作用是把動詞接到後面的東西上（原因在〈歩いて行きます〉第二節）。 目前學過的接法有這些，前半的て形都是同一套變法：

接法例句意思出處
て形 ＋ います 本ほんを 読よんでいます 正在看書 9/2〈〜ています〉
て形 ＋ 行きます 駅えきまで 歩あるいて 行いきます 走路去車站 10/21〈歩いて行きます〉
て形 ＋ ください ここに 書かいてください 請寫在這裡 8/9〈什麼是五段動詞〉提過
七、有三個地方容易講錯
✗ 錯誤✓ 正確原因
歩くて 歩いて て形不是在原型後面直接加 て，要把最後的 く 換成 いて。
走て 走って 走る 是五段動詞（走ります），不是一段，る 要變成 って。
行いて 行って 行く 是唯一的例外，く 結尾卻變成 って。
