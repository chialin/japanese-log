台語線索 — 東西南北的音讀，三條台語規律一次到齊
上面四個是訓讀（ひがし・にし・みなみ・きた），日文自己的字，跟漢字音無關。 但一進到複合詞就換成音讀，而音讀全都能用台語推：

東 台語 tang（-ng 尾）→ とう（東京 とうきょう、東北 とうほく） —— -ng 拉成 う 長音，不是 ん
南 台語 lam（-m 尾）→ なん（南米 なんべい、東南 とうなん） —— -m 併進 ん
西 台語 se（無韻尾）→ せい（西洋 せいよう）／さい（関西 かんさい）
北 台語 pak（入聲 -k）→ ほく（北海道 ほっかいどう、東北 とうほく） —— 入聲 -k 變 く

這四個字剛好把三條規律湊齊了：-ng 拉長音、-m／-n 收 ん、入聲 -k 變 く。 詳細見 8/6 的音讀線索。
我的記憶小撇步 — ひがし 的 ひ 就是太陽（日）
ひがし 在古日語唸 pimukasi，後來變成 ひんがし，再變成現在的 ひがし。 日文的語源辭典一般把它拆成 ひ（日）＋ むか（向か）＋ し（方向）， 意思是「朝著太陽的那一邊」。早上太陽從東邊出來，所以記住開頭的 ひ＝日 就好。 （古語形式見 Wiktionary 東）
另外 ひがし（higashi）和 にし（nishi）都是 し 結尾，東西可以當一對記； 11/3 學的 東出口（ひがしでぐち） 也是這個 ひがし。

台語線索 — 台語 -m／-n 尾 → 日語收 ん
台語收 -m 或 -n 的漢字，音讀幾乎都收 ん：
寒 han → かん（寒気 かんき）｜ 近 kin → きん（近所 きんじょ、最近 さいきん）｜ 遠 uan → えん（遠足 えんそく）｜ 安 an → あん（安心 あんしん）
收 -m 的也一樣（日語沒有 -m 韻尾，一律併進 ん）： 心 sim → しん｜金 kim → きん｜ 三 sam → さん｜音 im → おん
台語線索 — 但台語 -ng 尾是拉長音，不是 ん
這是最容易搞混的地方。台語收 -ng 的字，日語通常變成 う／い 長音，而不是 ん：
東 tong → とう｜中 tiong → ちゅう｜ 光 kong → こう｜京 king → きょう｜ 明 bing → めい
⇒ 看到台語韻尾就能分：-m／-n 收 ん，-ng 拉長音。

2026 / 08 / 11時間詞：き系與あ系→
我的記憶小撇步 — き系／あ系
き ＝「既」（既成事實，已經發生了）→ 昨日きのう・今日きょう
あ ＝「after」（之後）→ 明日あした・明後日あさって
卡在中間想不起來時，先問自己「這件事發生了沒」，發生了就從 き 開頭找，沒發生就從 あ 開頭找。
台語線索 — 正式那欄才接得上台語
・昨 台語 tsak → さく（昨日さくじつ）
・明 台語 bing → みょう（明後日みょうごにち）
・本 台語 pun → ほん（本日ほんじつ）
・日 台語 jit → にち／じつ（入聲 -t → ち／つ）
所以順序是：口語那欄靠き系／あ系記，正式那欄靠台語音讀記，兩邊各有各的鑰匙。
台語線索 — 先・今・来 的台語音讀
・先 台語 sian → せん（先週・先月・先生）
・今 台語 kim → こん（今週・今月）—— -m 尾對到 ん
・来 台語 lai → らい（来週・来月・来年）—— 幾乎一模一樣
・昨 台語 tsak → さく（昨年・昨夜・昨日さくじつ）—— 入聲 -k → く
⚠️ 但 昨日きのう・今日きょう・今年ことし 是固有詞讀法， 接不上台語，那幾個要靠上面的き系／あ系去記。
2026 / 08 / 11助詞「を」的三種用法→
我的記憶小撇步 — 一句話串起三種
三種其實是同一個意象：を 標的東西，都被動詞「穿過」了一遍。
・穿過一個物 → 動作落在它身上（映画えいがを見みる）
・穿過一個空間 → 走過去（橋はしを渡わたる）
・穿過一道邊界 → 出來了（家いえを出でる）
を 這個字形本身就像一條線穿過兩橫，可以拿來當圖像記。

・Ⅲ類只有 2 個（する・来る）→ 先排除

2026 / 08 / 12否定的說法→
我的記憶小撇步 — 「じゃ」是「では」念快的結果
正式書寫會看到 学生ではない，口語把 では 念成 じゃ → 学生じゃない。
兩個是同一個東西，じゃ 只是口語版，看到 ではない 不用當成新句型。
我的記憶小撇步 — は 是「先舉起來，再說它怎樣」
は 的工作是把某個東西提出來當話題，而否定天生就是在講 「這個東西不是這樣」——先把它舉起來再打叉，語感上很順。
所以規律是：否定句 → 想都不用想，先用 は。
順帶一提，這也解釋了為什麼「私わたしは肉にくを食たべない」聽起來自然—— 先舉出「我」，再說我不吃肉。
台語線索 — 学生（がくせい）＝ 台語的 hak-sing
「学」台語念 hak，入聲 -k 到了日文會變成 く → がく。
同一條線還有：薬やく（iok）、各かく（kok）、 国こく（kok）——台語念起來收 -k 的字，日文音讀多半收 く。
2026 / 08 / 12過去・現在・現在進行→
我的記憶小撇步 — 過去記號只有一個「た」
食べた、行いった、 高たかかった、学生がくせいだった。
看到 た 就想到「已經」——這條線一路通到底，不會再有第二個過去記號。
連否定的過去也一樣：ない 先變成 なかっ，再掛上同一個 た。
我的記憶小撇步 — 開關與燈
Ⓐ ＝ 按著開關不放（動作本身在持續）
Ⓑ ＝ 按一下開關，燈就一直亮著（動作結束了，狀態還在）
判斷方法：問自己「這個動作能不能持續十分鐘？」
「読む」可以讀十分鐘 → Ⓐ；「住む」不是一直在做的動作 → Ⓑ。
兩種都是在說「現在這個狀態成立」，所以日文用同一個形。
我的記憶小撇步 — 中文用「加字」，日文用「換尾巴」
中文講時間是往句子裡塞詞：昨天、明天、已經、等一下——不塞也能講完一句話。
日文講時間是換動詞的尾巴：る ↔ た——不換就講不完一句話。
所以中文人學日文最不習慣的不是「規則難」，是「躲不掉」： 每次開口都被逼著表態這件事是過去還是沒過去。
