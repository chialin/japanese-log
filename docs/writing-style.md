# 課程頁的中文寫法

寫 `lessons/`、`tadoku/`、`resources.html` 等頁面的中文時要遵守的規則。
CLAUDE.md〈中文的寫法〉放的是標題句型對照表，這份檔案補充語氣和用字上的細節，兩份一起看。

整體的方向是：頁面要讀起來像一篇**為 Scarlett 寫的教學文章**，用**台灣中文**，
語氣像當面跟同學解釋一樣，口語、好懂。

## 一、標題要直接講出那一段在說什麼

這是會長期累積的學習日誌，之後回頭查資料時，要一眼就看懂那一節在教什麼。
所以標題要平實，不要用比喻或奇怪的形容詞。

| 原本 | 改成 |
|---|---|
| ている 的兩張臉 | ている 的兩種意思 — 動作進行中與結果狀態 |
| 八格全景 — 一棵樹看完 | 動詞八個形的全貌 |
| 四個尾巴全包 | 一個動詞總共只要記四個字尾（る・ない・た・なかった） |
| 一、七格時間軸 | 一、以今天為主軸，列出前後幾天的說法 |
| 七、速記表 | 七、最後把比較的說法放在一起看（寫出結論，不叫「整理成一張表」） |

- 「一、二、三」的編號可以留著，重點是編號後面那句話要有意義。
- 不要拿數量當主題（「七格」「五個詞」）。
- 比喻和聯想可以寫在 `.mnemonic` 紅貼紙裡，正文和標題要平實。

## 二、開頭的「讀完這篇可以這樣說」要口語

第一塊 `.tip` 先用一句話講什麼情境會用到，接著用 `<ul class="tip-list">` 條列讀完可以做到的事（2026-11-07 起改成條列，比較好懂）。
每一條寫成「可以做什麼」的完整短句（用 〜 說「…」、分清楚 A 和 B），不要只放名詞。

範例（[X が一番〜です](../lessons/2026-11-07-ichiban-hayai.html)）：

> 想說「新幹線最快」「這個最便宜」，日文用 一番。這是「最〜」系列的第一篇，讀完這篇可以：
> - 用 X が一番〜です 說「X 最〜」，形容詞本身不用變
> - 知道 一番 是「第一號」，所以是「最」
> - 知道第一名後面接 が，不接 は
> - 分清楚 はやい 的兩個漢字：速い 是速度，早い 是時間

## 三、不要寫「賣關子」的文案腔

賣關子是先丟出一個問題，再用破折號停一下「揭曉答案」，想製造戲劇感。
廣告文案和 AI 寫的文章很常這樣寫，放在教學文章裡讀起來很怪。
判斷方法：**當面跟同學講的時候會不會這樣說？** 不會的話就改成直接講。

| 避免 | 改成 |
|---|---|
| 答案只有一句話——は 前面要放名詞 | 原因是 は 的前面要放名詞 |
| 日文沒有這麼方便： | 日文不一樣： |
| 學會這一步，一整組「多高、多長、多大」都能問了 | 用同樣的方法，也可以問多高、多長、多大 |
| 規則本身很簡單，真正容易出錯的是… | 規則不難，比較容易弄錯的是… |

- 內文少用破折號（——），大部分換成逗號或冒號就可以。

## 四、時間用絕對的說法

內文不要寫「今天」「昨天」「上次」「剛剛學的」，隔幾個月回頭看就不知道指哪一天。
改用篇名、日期，或「本篇」「本課」。

- ✗ 今天造句用的那一種 → ✅〈助詞「を」：動作的對象〉那篇造句用的
- ✗ 今天的五個字 → ✅ 本課的六個字（順便核對數量對不對）
- 例外：課程標題本身的「今日の単語 — …」是老師課上的命名，不用改。

## 五、其他小規則

- 每個小節開頭先用一兩句話帶入，不要一進去就丟表格。
- 內文的數量用中文寫（三拍、四個、兩天前），阿拉伯數字留給真正的數據（時刻、百分比、日期）。
- 概念難懂的時候，用中日對照的例子來說明，不要堆抽象的術語。
- 寫完要從頭讀一遍：抓語意錯誤、不像中文的句子、全形半形符號不一致。
