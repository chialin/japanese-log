# 漢字音讀對照表 — 設計文件

日期：2026-08-05
狀態：設計完成，待實作

## 問題

學習者累積了 60 幾篇課程、207 個標過假名的漢字，但**同一個漢字在不同課出現時，看不出彼此的關聯**。
「会」教過四次（会社・会話・会う・教会），學的時候都當成新詞背，沒察覺音讀都是 かい。

日語音讀跟台語都保留中古漢語的層次，對這位母語含台語的學習者來說，這是最省力的記憶捷徑，
但目前完全沒有被系統性地呈現出來。

## 目標

1. 課程頁上，讀到某個字的當下就知道「這個字你在別的地方看過」
2. 有一個可以事後複習的總表，看得到每個漢字的讀音分支與遇到順序
3. **全自動**——寫完新課跑一個腳本就更新，不需要手動維護任何資料表

## 非目標（明確排除）

- **漢字搜尋框**：規模只有 200 多字，瀏覽器 Cmd+F 就夠
- **筆順動畫／字源**：已由 `lessons/2026-05-17-*-jigen.html` 與 `assets/kanjivg/` 處理，不重複
- **精確台語拼音**：見下方「台語線索」一節的授權說明
- **未出現在課程裡的漢字**：只收學過的，不做通用字典
- **一字一頁的靜態檔**：先不做，理由見「kanji.html」一節；日後可由同一支 build 腳本補

## 架構

```
                       scripts/build-kanji.mjs
                                 │
        ┌────────────────────────┼────────────────────────┐
        │                        │                        │
  掃全站 <ruby>            data/kanji-readings.json    產出
  抽出出現記錄              （KANJIDIC2 子集，          ├── kanji.html（索引格，~25KB）
  (漢字,單字,讀音,          由 fetch-kanjidic.mjs      ├── js/kanji-data.js（全量，~45KB
   頁面,日期)                一次性下載後進版控）        │      只有 kanji.html 會載）
                                                       └── js/kanji-index.js（~2KB
                                                              課程頁徽章用）
                                                          │
                                              js/kanji-link.js（執行期）
                                              由 site-chrome.js 載入
                                                          │
                                              課程頁徽章 ＋ 頁尾連結
```

### 為什麼掛在 site-chrome.js

`js/site-chrome.js` 已載入於 96 頁中的 95 頁。課程頁的徽章與頁尾連結掛在這個既有載入點上，
**過去 60 幾篇課程一頁都不用改**，且回溯生效。

## 元件

### 1. `scripts/fetch-kanjidic.mjs`（一次性，之後只在有新漢字時重跑）

- 下載 KANJIDIC2（EDRDG，CC BY-SA 4.0）
- 只抽出**課程中實際出現過的漢字**，存成 `data/kanji-readings.json`：

```json
{ "会": { "on": ["カイ", "エ"], "kun": ["あ.う"] },
  "日": { "on": ["ニチ", "ジツ"], "kun": ["ひ", "-び", "-か"] } }
```

- 產物進版控，之後建置不需連網
- 授權標註寫在 `kanji.html` 頁尾（比照 `assets/kanjivg/` 既有做法）

### 2. `scripts/build-kanji.mjs`（每次寫完新課要跑）

**輸入**：`lessons/*.html`、`tadoku/*.html`、`readings/*.html` 的 `<ruby>基底<rt>假名</rt></ruby>`
＋ `data/kanji-readings.json`

**步驟**：

1. **抽出現記錄**——每個 ruby 產生一筆 `{漢字, 單字, 整體讀音, 檔名, 日期}`。日期取自檔名 `YYYY-MM-DD`。
2. **讀音對齊**——把單字讀音切給各個漢字：
   - 逐一比對該漢字在 `kanji-readings.json` 裡的候選讀音（片假名音讀轉平假名、去掉 `.` 之後的送假名、去掉 `-` 前綴）
   - 比對時同時嘗試**變音形式**：連濁（か→が、は→ば／ぱ、た→だ、さ→ざ）、促音（尾音 つ/ち/く/き→っ）、
     長音（う 結尾）
   - 命中就把單字掛到該讀音分支，並標記 `音讀` 或 `訓讀`
   - **對不上就丟進「その他 / 未分類」分支**，仍然出現在時間軸上，不會消失
   - 已知會對不上的情況：熟字訓（今日 きょう、一昨日 おととい）、整詞 ruby 且多漢字時的歧義
3. **產出 `kanji.html`**——索引格（見下節），不內嵌任何漢字詳細內容
4. **產出 `js/kanji-data.js`**——全量資料，只有 `kanji.html` 會載入：

```js
window.KANJI_DATA = {
  "会": { days: 4, on: { "かい": ["会話","教会","会社"] }, kun: { "あ": ["会う"] },
          other: [], timeline: [{d:"2026-07-10", f:"lessons/…jikoshoukai.html", t:"自己紹介", w:"会社"}] },
  ...
};
```

5. **產出 `js/kanji-index.js`**——精簡對照，只給課程頁徽章用（207 字約 2KB）：

```js
window.KANJI_INDEX = { "会": 4, "日": 8, "本": 6, ... };  // 漢字 → 出現天數
```

### 3. `kanji.html`（產物，進版控）— 索引格 ＋ 同頁展開

棕橘色票（比照 `lessons/*`），載入 `shared.css` ＋ `site-chrome.js` ＋ `js/kanji-data.js`，
掛在 `resources.html` 底下。

**不一次列出所有漢字卡**——頁面上半部是索引格，點字才在下方展開詳細內容。
這是為了讓字數從 207 長到 1000 以上時，頁面結構不需要重做。

```
┌─ 篩選列 ────────────────────────────────┐
│ [全部 207] [3 天以上 14] [多音字] [台語線索]│
├─ 索引格（依出現天數排序）──────────────────┤
│  日8  本6  会4  今4  行4  人4  車3  駅2 … │  ← .kanji-tile
│  （出現 ≥3 天的字用 --accent-pale 底標出）  │
├─ 詳細卡（點字後在此展開，不重載頁面）────────┤
│  会  · 遇過 4 天 · 單一音讀                 │
│  [かい] 会話・教会・会社     ← 音讀 棕橘     │
│  [あ]   会う                ← 訓讀 金茶     │
│  — 遇到的順序 —                            │
│  ○ 7/10 自己紹介 — 会社                    │
│  ○ 8/05 どこですか — 教会                  │
│  🧠 台語線索（.mnemonic 紅貼紙）            │
└────────────────────────────────────────┘
```

**篩選列**（純前端過濾索引格，不重載）：

| 分類 | 條件 |
|---|---|
| 全部 | 所有出現過的漢字 |
| 3 天以上 | `days >= 3`——目前 14 字，跟課程頁徽章同一個門檻 |
| 多音字 | 音讀 ＋ 訓讀分支合計 ≥ 2 種讀音（日・人・車…） |
| 台語線索 | 音讀韻尾推得出中古入聲／鼻音尾的字（見下節），也就是「唸台語就會的字」 |

**行為**：
- 點字磚 → 以 `history.replaceState` 更新網址為 `kanji.html#会`，詳細區即時換掉（不重載）
- 直接開 `kanji.html#会`（課程頁徽章的連結）→ 進頁時自動展開該字並捲到詳細區
- 沒有 hash 時，預設展開出現天數最高的字

**為什麼不做一字一頁**：實測資料量，全量 JSON 僅 33 KB（207 字／382 筆記錄），
即使長到 1000 字也只有約 260 KB；而一字一頁需要 207 個檔案各自重複約 3 KB 的 HTML 骨架
（光骨架就多 620 KB），且每次 build 全部重寫、git diff 難讀。
若日後真需要列印或做成 EPUB，再補一支「輸出單頁」的腳本即可——build 腳本已握有全部資料。

### 4. 台語線索（規則推導，不查辭典）

**不需要台語辭典**——中古漢語的韻尾可以從日語音讀本身推出來：

| 音讀收尾 | 中古 | 台語多半 | 例 |
|---|---|---|---|
| 〜ち／〜つ | 入聲 -t | -t | 日 にち、一 いち |
| 〜く／〜き | 入聲 -k | -k | 局 きょく、薬 やく |
| 〜う（歷史假名為 〜ふ） | 入聲 -p | -p | 十 じゅう、急 きゅう |
| 〜ん | 鼻音 -n/-m/-ng | -n/-ng | 電 でん、練 れん |

貼紙文案由音讀自動生成，例：
> 🧠 **台語線索**：音讀收 **く** → 中古入聲 **-k** → 台語也收 **-k**，唸唸看。同款：薬 やく・局 きょく。

推得出線索的字同時被標記 `hasTaigi: true`，供索引格的「台語線索」篩選使用。
「同款：…」清單取自**同一個韻尾分類下、學過的其他漢字**（由 build 腳本自動湊），
所以會隨著學的字變多而自己長出來。

**刻意不印出具體台語拼音**：① 教育部台語辭典為 CC BY-ND，抽子集進版控在授權上站不住腳
② 學習者本身講台語，唸出來就能自我驗證，比機器給的拼音更可靠。

只有**音讀**分支會有這張貼紙；訓讀是日文固有詞，跟漢字音無關，不出現。

### 5. `js/kanji-link.js`（執行期，由 `site-chrome.js` 動態載入）

在 `lessons/`、`tadoku/`、`readings/` 底下的頁面執行（首頁與資源頁跳過）：

1. 掃頁內所有 `<ruby>` 的漢字
2. **徽章**：出現天數 **≥ 3 天**的字，在所屬 `.word-item` / `.turn` / `.ta-card` 右側插入
   `<a class="kanji-chip" href="../kanji.html#会">会 ×4 →</a>`
   （門檻 3 天＝目前 14 個字符合，避免每張卡都長徽章）
3. **頁尾行**：在 `<site-footer>` 前插入
   `📚 本課出現的漢字：会・電・車・駅 — 到漢字表看它們在別課的用法 →`
4. 找不到 `KANJI_INDEX` 時靜默跳過（例如尚未跑過 build 腳本），不報錯、不影響頁面

### 6. `shared.css` 新增

- `.kanji-chip` — 課程頁徽章（白底、`--accent-soft` 細框、圓角 3px）
- `.kanji-footer` — 頁尾那一行
- `.kanji-tile` / `.kanji-grid` / `.kanji-filter` — 漢字表頁的索引格
- `.kcard` / `.khead` / `.kbig` / `.kbranch` / `.ktimeline` — 漢字表頁的詳細卡

沿用既有色票，不新增顏色：音讀＝`--accent`，訓讀＝`#a9762a`（same-day 的金茶），
台語線索＝既有的 `.mnemonic` 紅貼紙。

## 資料流與失效處理

| 情況 | 行為 |
|---|---|
| 新課寫好但沒跑 build | 徽章與頁尾行不出現，頁面完全正常（graceful） |
| 漢字沒有 ruby 標音 | 不收——只收「教過的」，避免內文散字混進來 |
| 讀音對不上任何分支 | 進「その他」分支 ＋ 仍列在時間軸 |
| 熟字訓（今日・一昨日） | 必然對不上，走「その他」；可接受 |
| 同一天多篇課用到同一字 | 出現天數以**天**計（不重複計數），時間軸則每篇各一筆 |

## 驗收標準

1. `node scripts/build-kanji.mjs` 跑完後，`kanji.html` 索引格列出全部 207 字，出現 ≥3 天的 14 字有標示
2. 「日」卡片正確分出 にち／じつ／ひ・び／か 四支，且各支底下的單字掛對
3. 「会」卡片顯示單一音讀 かい，且 `会う` 正確歸到訓讀 あ
4. 隨機開三篇**舊**課程（未修改過的），高頻字旁出現徽章，頁尾出現漢字行
5. 徽章連結點下去能跳到 `kanji.html` 對應漢字的位置
6. 把 `js/kanji-index.js` 暫時移走，所有頁面仍正常顯示（無 console error）
7. 台語貼紙只出現在音讀分支，且韻尾規則正確（局 きょく → -k）
8. 點索引格任一字，詳細區即時更新且網址變成 `kanji.html#<字>`，不重載頁面
8b. 四個篩選（全部／3 天以上／多音字／台語線索）都能正確過濾，且「台語線索」只留下有紅貼紙的字
9. 直接開 `kanji.html#日` 會自動展開「日」並捲到詳細區
10. 課程頁只載入 `js/kanji-index.js`（約 2KB），不載入全量的 `js/kanji-data.js`
