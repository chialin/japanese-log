買かう → 買かいます、行いく → 行いきます

動詞・活用 ＋ 單字 · Verbs & Vocabulary · 2026 / 08 / 11

兩個五段動詞的マス形實作，加上「に」指目的地，再收五個新單字

1.0x
💡 本篇要記的事
五段ごだん動詞變マス形只有一個動作：把字尾的「う段」換成同一行的「い段」，再加ます。
今天用 買かう 和 行いく 各走一次，並複習目的地助詞 に。
一、買う ⇒ 買います

買う 是 わ行（う・い・う・え・お ← 現代日語的わ行只剩 わ 和 を，中間那格就是 い）。 所以字尾 う → い，變成 かいます。
⚠️ 常見錯：不會變成「かうます」，也不會變成「かわます」。

かう
kau
原形（辭書形）
→
かい
kai
う段 → い段
→
かいます
kaimasu
マス形（禮貌）
📖 買う 的例句
パソコンを買かいます
pasokon o kaimasu
（我）要買電腦 — パソコン ＝ personal computer 的日式縮寫
彼かれはパソコンを買かいます
kare wa pasokon o kaimasu
他要買電腦
本ほんを買かいます
hon o kaimasu
買書
二、行く ⇒ 行きます

行く 是 か行：か・き・く・け・こ。字尾 く → き，變成 いきます。 同一招套到別的く結尾動詞也通：書かく → かきます、聞きく → ききます。

三、学校に行く

移動動詞（行く・来る・帰かえる）的目的地用 に 標出來， 句型固定是 ［地點］に ［移動動詞］。

📖 に ＋ 行きます
学校がっこうに行いく
gakkou ni iku
去學校（原形・對熟人講）
学校がっこうに行いきます
gakkou ni ikimasu
去學校（マス形・禮貌）
私わたしは映画えいがを見みます
watashi wa eiga o mimasu
我看電影 — 受詞用 を，跟目的地的 に 不同格
📝 に vs を 一句話分
に＝往哪裡（学校に行きます）｜ を＝對什麼做（映画を見ます）。
⚠️ 不會說「学校を行きます」，也不會說「映画に見ます」。

📝 「門」的四個親戚 — もん・とびら・ドア・と
中文一個「門」字，日文分成四個詞，差在指的是哪一部分：
詞指什麼例
門もん建築物／院子的大門、門口（整個門的構造，含門柱）正門せいもん・校門こうもん
扉とびら會開闔的那片門板本身（也指書的扉頁）扉とびらを開あける
ドア西式的房門（外來語 door，最日常）ドアを閉しめる
戸と日式的拉門、板門雨戸あまど・引ひき戸ど
一句話抓：門＝門口那個「地方」，扉／ドア／戸＝會動的那「一片」。 日常講房間的門就用 ドア，講學校大門用 門。
🧠 我的記憶小撇步 — 扉（とびら）怎麼記
と（戸）＋びら（ひら／平ら） —— 門的那一「片」平板。同一個 ひら 也在 一枚いちまい的「片」、開ひらく 裡面， 都是「平平一片、攤開」的意象。
字形也順：扉 ＝ 戸（門）＋ 非（左右兩扇像翅膀展開） —— 兩扇對開的門板。
🧠 我的記憶小撇步 — 涙（なみだ）怎麼記
なみだ 拆成 なみ（波）＋だ（出だ／垂だ）—— 眼淚像一波一波湧出來。日文語源學上也真的認為 なみだ 跟「なみ（波）」同源，不是硬湊的。
字形再補一刀：涙 ＝ 氵（水）＋ 戻（返回），水一再回來 ＝ 眼淚。
🧠 我的記憶小撇步 — 門・名・映 用台語接音讀
・門 台語 bun → もん（専門 せんもん、正門 せいもん）
・名 台語 bing → めい（有名 ゆうめい、名刺 めいし）—— 但 名前なまえ 的 な 是訓讀，別混
・映 台語 ing → えい；画 台語 ue → が。鼻音尾 -ng 對到 えい 這條在日台之間很整齊
・鳥 台語 tsiau → 音讀 ちょう（白鳥 はくちょう）；但單獨講「鳥」用訓讀 とり
五、映画 ⇒ えーが

えい 實際上唸成長音 えー，不是清楚地唸出「e-i」兩個音。 寫成 えいが、唸成 えーが。

えいが
寫（假名）
→
えーが
唸（實際發音）

而且 映画えいが 是 平板型——除了第一拍略低，之後一路平平不掉下來， 不要像中文那樣在某個字上壓重音。

照老師板書的箭頭標法：↗ 往上升、 ↘ 往下掉、 → 維持平平的，箭頭標在它作用的那個音前面。

→えーが→
平板型 —— 第一拍 え 略低，之後 ーが 一路平平不下降， 後面接助詞（映画えいがが…）也照樣平著接下去。
⚠️ 最容易錯的地方
不要像中文那樣在「画」上壓重音唸成「えいガ↘」。 平板型的判準是整個字唸完都沒有下降點——這正是你自己抓到的「都是平平的念法」。

📝 同一條規則的其他字
先生せんせい → せんせー ｜ 学生がくせい → がくせー ｜ 時計とけい → とけー ｜ 英語えいご → えーご
同理 おう／おお 也唸長音 オー：学校がっこう → がっこー。
六、課後複習小測驗 · Self-Quiz
✏️ 試試看

1. 把「行いく」變成マス形。
2. 把「買かう」變成マス形。
3. 用日文寫「我去學校」（禮貌形）。
4. 用日文寫「他買電腦」。
5. 「映画えいが」實際上怎麼唸？為什麼？

🔍 點擊查看解答
1. 行いきます（く → き ＋ ます）
2. 買かいます（う → い ＋ ます）
3. 私わたしは学校がっこうに行いきます。（目的地用 に）
4. 彼かれはパソコンを買かいます。（受詞用 を）
5. 唸成 えーが。「えい」在現代日語一律讀成長音 エー，不分成 e＋i 兩拍；而且是平板型，後面平平不下降。
