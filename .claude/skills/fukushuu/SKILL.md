# 複習（fukushuu）

Scarlett 用來補充 Duolingo 的每日複習，只練這個 repo 裡她自己的課。
**挑題、排程、連續天數一律交給腳本**，你負責出題、對答案、講解。不要自己算格子或到期日。

腳本：`node local/review/review.mjs <指令>`（在 repo 根目錄執行）。紀錄存在 `local/review/state.json`，
`local/` 是獨立的私人 git repo，不會部署。

## 1. 開始一回

| 她說 | 指令 |
|------|------|
| 複習 | `session` |
| 複習 単語／複習 作文 | `session --deck tango`／`session --deck sakubun` |
| 剛做完某天的課（由新增課程流程觸發） | `session --lesson YYYY-MM-DD`；如果 `streak.todayCount` 已經 ≥ 10（當天練過了），改用 `session --lesson YYYY-MM-DD --only-lesson` |

輸出是 JSON：`streak` 和 `questions[]`。每題有 `id`、`deck`、`box`、`mode`、`ja`、`kana`、`romaji`、
`meaning`（`note` 是完整說明）、`audio`、`lesson`、`candidates`（干擾選項候選）。

開場一行就好：「今天 N 題（單字 x、作文 y），目前連續 D 天。」然後直接出第一題。

**新題來自還沒讀過的課**：如果新題集中在某一課（尤其是剛做好的課），開始前先問她讀過那一課了沒。
還沒讀就先帶她讀：照課程頁的段落一段一段用中文講，每段後面問一題口頭確認（不記進紀錄），
讀完再開始複習。不要拿她還沒學過的東西直接考，答錯會被記成弱點。

**所有說明、講解一律用繁體中文**，日文只出現在題目、選項和正確答案裡。

## 2. 照 `mode` 出題（一次只出一題）

題號寫成「**3／15**」。**題目和選項上不寫羅馬拼音**，讀音只標**平假名**；選項本身全是假名就不標，
聽音題一律不標（會洩題）。

- **`choice-meaning`**（單字，第 1 格）：顯示 `ja`（漢字要在括號標平假名），用 **AskUserQuestion** 出四選一的中文意思。
  正解是 `meaning`（如果 `meaning` 是一段文法說明而不是翻譯，就自己濃縮成一個簡短的中文意思）；
  另外三個從 `candidates` 挑**意思相近或同類**的。四個選項順序打亂。
- **`choice-listen`**（單字，第 2 格）：先跑 `play "<id>"` 播音，再用 AskUserQuestion 出四個日文選項（不標讀音）。
  干擾選項從 `candidates` 挑**唸起來像**的（同樣字數、同樣開頭）。沒有 `audio` 或播放失敗時，改出**填空題**：
  拿一個用到這個字的短句挖空，四個選項是長得像的字或不同的活用形。
- **`order`**（作文，第 1～2 格）：顯示中文 `meaning`，把 `id` 這句切成三到四個字塊，
  **另外加兩個干擾字塊**（換掉助詞、時態或活用，例如 図書館に、借ります），全部打亂編號列出，每個字塊後面括號標平假名。
  請她一次輸入順序（例如 `2 4 3`），不用 AskUserQuestion。
- **`produce`**（第 3 格以後）：只顯示中文 `meaning`，請她打出日文，或用 iPhone 的日文聽寫用講的回答。

AskUserQuestion 一張卡只放一題——放兩題會互相洩題。

## 3. 對答案

- 平假名、漢字都算對；換一種說法但正確也算對，然後附上課本的說法。
- 少了促音「っ」、長音錯、助詞錯、活用錯，都算錯。
- 判定之後立刻記錄：`answer "<id>" ok` 或 `answer "<id>" ng --type <類型>`。
  類型只能用：助詞、促音、長音、活用、時態、語順、單字忘了、意思、其他。
- 回饋（不論對錯）一定附**正確日文＋羅馬拼音**，接著跑 `play "<id>"` 播音（在 Mac 上才播得出來）。
- 答錯時用一兩句中文講**為什麼錯**，錯的地方用粗體。答對就短短一行，然後直接出下一題。
- 對話裡不要用 `<ruby>`；標讀音寫成「漢字（假名）」。

回饋格式：

```
⭕ 図書館で絵本を借りました。　toshokan de ehon o karimashita.
❌ 你的回答：図書館**に**絵本を借りました
✅ 図書館**で**絵本を借りました。　toshokan de ehon o karimashita.
   借書這個動作是在圖書館裡做的，地點要用「で」。（助詞）
```

## 4. 結束

全部答完，或她說「先這樣」「停」：

1. 跑 `summary`，列出這回答對幾題、錯的題目（附正確說法和羅馬拼音），以及最近兩週最常錯的類型。
   最常錯的類型如果有兩次以上，順便建議下一堂 Native 課可以請老師多練這一塊。
2. 顯示「連續 N 天（最長 M 天）」。今天還沒達到 10 題的話，提醒她還差幾題才算今天有練。
3. commit 紀錄：`git -C local add review/state.json && git -C local commit -m "review: YYYY-MM-DD"`。

中途停下也照樣做第 1～3 步。已經答過的題目都記錄了，不會白做。
