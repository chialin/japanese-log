助詞「を」的三種用法

文法 · Grammar · 2026 / 08 / 11

受詞、通過的場所、離開的起點 — 一個假名三種角色

1.0x
💡 本篇要記的事
を 只有一個身分：助詞，從來不當一般假名用。
看到 を 就知道前面那個名詞是被後面的動詞「處理」的對象 —— 差別只在處理的方式有三種。
唸 o（跟 お 同音），鍵盤打 wo。
⚠️ を 不是「お」的另一種寫法
兩個唸法完全一樣，但分工乾淨：を 專門當助詞（映画を見ます）， お 才進單字裡（お茶おちゃ・男おとこ）。
寫單字時不會用到 を，寫助詞時也不會寫成 お —— 跟 は 當助詞唸 wa 是同一種老規矩的另一面。
一、直接受詞 — 對什麼做
1
動作的對象
Direct object

最常見的一種，也是〈助詞「を」：動作的對象〉那篇造句用的。 動詞是及物的（有東西可以「被做」），那個東西就掛 を。

［名詞］を ［及物動詞］
📖 例句
映画えいがを見みます
eiga o mimasu
看電影 — 看的對象是電影
本ほんを読よみます
hon o yomimasu
讀書 — 讀的對象是書
パソコンを買かいます
pasokon o kaimasu
買電腦 — 買的對象是電腦
料理りょうりを作つくります
ryouri o tsukurimasu
做菜 — 做的對象是菜
二、通過的場所 — 從哪裡經過
2
移動的路徑
Path of motion

這裡的 を 標的是場所，不是東西 —— 但邏輯一樣： 動作「作用在」那個空間上，人穿過它。最容易漏掉的一條，因為中文會說「在公園散步」， 很容易誤用成 で 或 に。

［場所］を ［移動動詞］ 渡る・歩く・散歩する・通る・曲がる …
🚶 例句
橋はしを渡わたります
hashi o watarimasu
過橋 — 橋是穿過去的東西，不是終點
道みちを歩あるきます
michi o arukimasu
走在路上 — 沿著路移動
公園こうえんを散歩さんぽします
kouen o sanpo shimasu
在公園散步 — 在公園裡面到處走動
⚠️ 公園を散歩 vs 公園で遊びます
を＝在裡面移動、走遍（散歩・歩く・走る）
で＝在那裡做某件事，人待在同一塊地方（遊ぶ・食べる・work）
判準：動作本身有沒有「位移」。有 → を；沒有 → で。
三、離開的起點 — 從哪裡出來
3
脫離的場所
Point of departure

人原本在裡面，動作是「脫離出來」。這個 を 標的是離開的那個範圍。

［場所・組織］を ［離開動詞］ 出る・降りる・卒業する …
🚪 例句
家いえを出でます
ie o demasu
出門、離開家 — 從家這個範圍裡出來
電車でんしゃを降おります
densha o orimasu
下電車 — 從車廂裡出來
大学だいがくを卒業そつぎょうします
daigaku o sotsugyou shimasu
大學畢業 — 「離開」不一定是實體空間，組織也算
📝 電車を降ります ⇄ 電車に乗のります
下車用 を（脫離）、上車用 に（進入某個點）—— 兩個剛好是一對，一起記最省事。
四、三種用法一次看
用法を 標的是例句動詞長什麼樣
① 直接受詞被處理的東西 映画えいがを見みます 及物動詞（見る・読む・買う・作る）
② 通過場所穿過的路徑 橋はしを渡わたります 有位移的移動動詞（渡る・歩く・散歩する）
③ 離開起點脫離的範圍 家いえを出でます 離開動詞（出る・降りる・卒業する）
🧠 我的記憶小撇步 — 一句話串起三種
三種其實是同一個意象：を 標的東西，都被動詞「穿過」了一遍。
・穿過一個物 → 動作落在它身上（映画えいがを見みる）
・穿過一個空間 → 走過去（橋はしを渡わたる）
・穿過一道邊界 → 出來了（家いえを出でる）
を 這個字形本身就像一條線穿過兩橫，可以拿來當圖像記。
📝 跟其他助詞的分界
想表達用例
往哪裡去（終點）に／へ学校がっこうに行いきます
從哪裡經過（路徑）を公園こうえんを歩あるきます
從哪裡離開（起點）を家いえを出でます
在哪裡做某事（定點）で公園こうえんで遊あそびます
一句話抓：に＝進去某個點，を＝穿過或脫離某個範圍，で＝待在那裡做事。
⚠️ 兩種「不能用 を」的情況
① 自動詞沒有受詞，改用 が：雨あめが降ふります（下雨）
② 「會／懂／喜歡」這類句型也把 を 換成 が： 日本語にほんごが分わかります（懂日文）
第 ② 條之後遇到再細講，現在只要知道「わかります・できます・好きです 前面不是 を」。
五、課後複習小測驗 · Self-Quiz
✏️ 填入 を / に / で

1. 学校がっこう（　）行いきます。
2. 本ほん（　）読よみます。
3. 橋はし（　）渡わたります。
4. 電車でんしゃ（　）降おります。
5. 公園こうえん（　）遊あそびます。
6. 「大學畢業」用日文怎麼說？為什麼用 を？

🔍 點擊查看解答
1. に（或 へ）— 目的地、終點
2. を — ① 直接受詞
3. を — ② 通過的場所，橋是穿過去的路徑不是終點
4. を — ③ 離開的起點；上車則是「電車に乗のります」
5. で — 遊びます 沒有位移，人待在公園裡做事；若改成「公園を散歩さんぽします」就要用 を
6. 大学だいがくを卒業そつぎょうします。畢業＝離開那個組織，屬於第 ③ 種用法。
